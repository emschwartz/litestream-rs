## D315. Every patch in the tree must apply in the land gate; the fadvise bench arm is dropped (delegated)

Status: decided · Decided by: delegated, Claude (claude-sonnet-5-5), 2026-11-27, for the owner · Recorded by: Claude (claude-sonnet-5-5)

- **Question:** `crates/compat/bench-patches/fadvise-dontneed.patch` stopped applying on main and CI stayed green, because `just planted-bugs-apply` ran only in the nightly workflow, not in `just check`. What runs it, and what happens to the patch?
- **Choice:** the owner measured the fadvise experiment (no benefit) and dropped it: the patch file and the bench's `fadvise` arm are gone, and `read-pace` and `read-twice` still apply. `planted-bugs-apply` joins `just check`, so the `check` job of every pull request refuses a stale planted-bug or bench patch. The nightly job stays, for its early naming of a stale patch.
- **Why:** a patch that does not apply is a plant or an arm that cannot run, found weeks later. The check is seconds and builds nothing.
- **Cost if wrong:** a change that moves a line near a planted site must re-express the patch in the same pull request (the earlier rule let it land and fixed the patch afterwards).
- **Links:** `justfile` (`planted-bugs-apply`), `docs/planted-bugs.md`.
