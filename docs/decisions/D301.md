## D301. A planted-bug entry's commit must be on main, checked by `just planted-bugs-names` (delegated)

Status: decided · Decided by: Claude (claude-sonnet-5-5), **delegated**; the owner can overturn it · Recorded by: Claude (claude-sonnet-5-5) · Amends: `docs/planted-bugs.md` (the `fix` field)

- **Question:** the entry `restore-tail-restarts` named `81aa67141`, a commit of the pull request's own branch. The squash merge dropped it, so the reference pointed at nothing. A scan found 48 more entries naming a branch commit the same way. How is a dangling `fix` kept from recurring?
- **What Go does:** nothing comparable; the ledger is this project's own.
- **Decision:** `--names` (in `just check`) looks up every `fix` written as a commit (seven to forty hex digits) with `git merge-base --is-ancestor <fix> origin/main`. Other forms (`plant`, `none`, `claude/<branch>`, a note) name no commit and are not looked up. The check uses `origin/main` and not HEAD: a branch's commit is an ancestor of the pull request's HEAD, so a HEAD check passes on the branch and fails only on `main` after the merge. A fix that names a branch commit therefore fails its own pull request, and the author writes `claude/<branch>` until the squash commit exists. The 49 entries that named branch commits now name the squash commit GitHub records for the pull request that held them (`gh api repos/<owner>/<repo>/commits/<sha>/pulls`; `wait-until-lock` names #448's commit, which the API no longer knows). The `check` job in `.github/workflows/ci.yml` fetches full history so the lookup has objects to walk.
- **Rejected:** accepting an ancestor of HEAD (the failure above, found only after the merge); skipping the check on a shallow clone (CI is the one place it must run); retiring the 49 entries (their plants still kill their tests; only the provenance was wrong).
- **Cost accepted:** a full clone in the `check` job (seconds); the 49 changed entry files make the next pull request's `planted-bugs-diff` run those entries once (about 5 minutes per 12); a `claude/<branch>` name is still unchecked and can outlive its branch.
- **Revisit if:** the `claude/<branch>` form is also found to mislead, or the full-history checkout costs real time.
- **Links:** `scripts/planted-bugs.py` (`dangling_fixes`), `scripts/test_planted_bugs.py` (`Fixes`), `docs/planted-bugs.md`.
