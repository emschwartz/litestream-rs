## D63. A boot never guesses the replica's end

Status: superseded by D173 (was: open to owner review) · Decided by: Claude, **delegated** (route from the parent session)

- **The case:** bucket rollbacks took transactions 1 to 4 and left 5, staging was wiped, and a boot listed behind a lag that showed nothing. The walk past the listing stopped after 3 missing transactions, short of 5, took the replica as empty, wrote a first sync and uploaded a new 4 below the replica's 5: the latest state went back with no signal (simulator seed 0x95a).
- **Rule:** the boot never concludes that the replica ends below an object it can see or find. An end it cannot prove is unknown, and unknown is a stop, not a guess.
  - (a) With nothing staged, nothing bounds what the replica may hold past the listing, so the walk goes to its cap (64 transactions) instead of stopping after 3 missing ones. With something staged the walk runs through the newest staged transaction, then stops at the gap, as before.
  - (b) A level-0 tail the reads judge torn is replaced by its staged copy only when no level 1 to 9 file already holds that transaction; otherwise the boot stops with `RemoteCorrupt`. The end the boot otherwise takes is the newest of every level the listing shows and every key the walk found, so it is never below a visible object.
- **Read cost:** past its gap window a walk names only the level-0 and snapshot keys (4 per transaction); inside it, every key (up to 20). A walk reads at most `WALK_READS_MAX` = 4 × 20 + 60 × 4 = 320 one-byte reads, about 264 with levels 1 and 2 in use. It runs to that bound only on a boot with nothing staged (a first start, a wiped or lost staging directory) or through a staged range far past the listing. A first start on an empty replica now costs about 250 more reads than before. The simulator's read budget charges each listing what the stores around it allow (D171).
- **Stop case:** a torn level-0 tail under a higher-level file that holds it. The replica then disagrees with itself; an operator decides (it is BOOT-16's narrower sibling).
- **Not covered:** a hole wider than 64 transactions below the newest file with nothing staged; a listing that hides everything past a hole on a restore (WORLD-42).
- **Revisit if:** a store charges reads enough that 320 per first start matters.
- **Links:** `crates/core/src/upload.rs` (`look_past`, `held_above`), `crates/core/src/probe.rs` (`walk`, `WALK_READS_MAX`), seed 0x95a in `crates/sim/tests/sim/histories/`.
