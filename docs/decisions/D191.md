## D191. A remedy for the copy's effect on an application is judged by a bar fixed before the measurement

Status: decided · Decided by: Claude (claude-sonnet-5-5), delegated · Recorded by: Claude (claude-sonnet-5-5)

- **Question:** issue 315 asks for a read-rate limit and a page-cache hint for the snapshot and verify copies, but AGENTS.md wants the effect measured before a knob lands. What does "brings it back" mean, so that the numbers cannot pick their own bar afterwards?
- **Choice:** the frame lives in `crates/compat/src/bench/plan.rs` (`IMPACT_FRAME` and the constants) and is frozen before the first timed run. The primary metric is the application's p99 read latency during the copy relative to the same application with no copy. A remedy meets the bar when its p99 is within 2 times that baseline and its copy takes no more than 4 times the unthrottled copy. The smallest change worth acting on is 25% in p99. The remedies are prototypes kept as patches beside the bench (`crates/compat/bench-patches`), applied to a scratch worktree and built into their own binaries; none is in the engine. A copy that reads every page twice is the known-bad control, and the run's conclusions stand only if it loses.
- **Why:** the 2 times bar is the least a user would call "back to normal" and the 4 times bound keeps a throttled copy from holding its read transaction (and so the WAL, and the replica's staleness) for hours. The 25% SESOI is a change a knob has to beat to be worth its documentation and its default. Patches keep the engine free of code whose value is unmeasured.
- **Cost accepted:** one machine, one disk type, MinIO sharing the disk and the page cache, a hot set with a 90/10 skew that is not any embedder's. A bar met here is evidence for the knob and not a guarantee for another machine. A bar set too tight sends a useful knob back for another round of hours of measurement.
- **Revisit if:** the A/A run shows the box cannot see 25% in p99 (the harness then stops), or the owner wants a different bar once the baseline's size is known.
