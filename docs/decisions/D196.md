## D196. The read budget charges a boot's identity check by the files it restores (delegated)

Status: decided · Decided by: Claude (claude-sonnet-5-5), **delegated** (route from the parent session) · 2026-11-24

- **Question:** the simulator's replica-reads law charged each boot a fixed 24 reads (D171, D173). A boot with nothing staged compares the database with the replica by restoring the replica's latest state (D170, D194), one read pass over every file the restore plan names. A swarm run with a second writer's file standing (a supervisor restarting the stopped engine 189 times) made 34,924 reads against a limit of 13,264: each restart read about 130 files. Is that an engine that re-reads too much, or a budget that omits a read the design accepted?
- **Choice:** the budget. D170 accepts one download of the replica's latest state on every boot that would otherwise stop, and the restore reads each file once. The law now adds, for every tick that began unbooted with nothing in staging, the number of files the replica held then, at 2 reads a file (a header and the body, as for a compaction input). The engine is unchanged.
- **Options considered:** make the engine remember that the check found the database different from the replica's tip (a new remembered state, refused by D173 and the caching rule); skip the check when a second writer's file stands (the engine cannot tell one from its own lost upload); exempt the identity check from the law (the law then cannot see a restore per tick).
- **Cost accepted:** a restart loop on a stopped engine (`other_writer` with the other writer's file standing and nothing staged) downloads the replica's latest state on every start, as D170 says. Under a supervisor that restarts every few seconds on a large database this is real egress. The law now allows exactly that, per boot-tick, and still fails a restore on a booted engine's ordinary ticks.
- **Revisit if:** a deployment reports a restart loop costing egress; the likely answer is a cheaper first check (the replica newest file's header against the local state) before the full restore.
- **Links:** D170, D171, D173, D194, `crates/sim/src/budget.rs` (`Spent::restores`), `crates/core/src/identity.rs`.
