## D305. A request beyond Go's is also allowed when it saves clearly more than it costs

Status: decided · Decided by: the owner (2026-11-27), amending D241 · Recorded by: Claude (claude-sonnet-5-5)

The owner's words: "an extra read to prevent reading gigabytes unnecessarily seems like a clear win".

- **Question:** D241 allows a request beyond Go's only to guard a Go defect. Should an extra request that avoids much larger cost be allowed too?
- **Go:** no rule; its request count per scenario is the baseline, because each request is billed.
- **Choice:** in the same scenario, an extra request is allowed when it avoids clearly more cost than it adds, counted in bytes downloaded or uploaded or in other requests. The comment at the request and a decision file say what it saves and what it costs when it misses. The first instance is the whole-copy read of a restore in docs/decisions/D304.md. The Go-defect case of D241 stands unchanged.
- **Cost accepted:** "clearly more" is a judgment, and a request that misses is billed for nothing; the decision file must state that miss cost.
- **Revisit if:** the extra requests add up to a visible share of the bill, or reviewers disagree on what "clearly" means.
