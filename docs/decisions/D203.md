## D203. A flag the binary cannot honour is an error, and the help is held to the parser (delegated)

Status: decided · Decided by: delegated, Claude (claude-sonnet-5-5), 2026-11-25, for the owner · Recorded by: Claude (claude-sonnet-5-5)

- **Question:** the rewritten documentation found the binary contradicting itself: `lsr restore --endpoint X s3://bucket/path` read the flag and dropped it, so the restore went to AWS; `lsr replicate -h` called two working flags refused; `lsr --help` left out `databases`, `ltx` and `wal` and ran a flag into its text. What does `lsr` do with a flag it cannot honour, and what keeps the help true?
- **Go's way:** Go's `restore` has no `-endpoint`: a bare replica URL carries its endpoint, region and path style as query keys (`s3://bucket/path?endpoint=http://host:9000`, `?region=`, `?forcePathStyle=true`; `cmd/litestream/main.go`, `NewReplicaFromConfig`). `lsr` already reads those keys through the daemon's URL reader.
- **Choice:** `--endpoint`, `--region` and `--force-path-style` stay `lsr`'s own spelling beside `--replica`, and beside a REPLICA_URL or a DB_PATH they are refused, the error naming the query form. `-config` and `-no-expand-env` beside `--replica` are refused (no config is read), `-o` with `--output` is refused (one flag twice), and `files --created-at` beside a directory is refused (nothing to read one by one). What Go itself takes and drops stays accepted and dropped, each named in the walk's list with its reason: `-no-expand-env` beside a URL, `-follow-interval` without `-f`. `-f` is still refused (#177).
- **Held by tests:** one table of every command, flag and form; each flag must change what the command line parses to, or be refused, or be listed as inert with a reason and shown to be inert (`every_flag_changes_the_command_or_is_refused`, and the same for `replicate`'s flags). `CommandName` lists every word the dispatcher takes, `parse` matches on it exhaustively and the help prints every one. Each Go-grammar command's help table is compared both ways with the flags its parser defines, and `replicate`'s usage text with its parser's. The help's flag column is as wide as its longest flag.
- **Why:** AGENTS.md: a request that cannot be met exactly is an error, never a quieter one. A dropped endpoint sends a restore to the wrong store with no word of it.
- **Cost if wrong:** a script that passed `--endpoint` with a bare URL (it never worked) now fails to start; the fix is the query on the URL. The `-o` and `--output` refusal and the `--created-at` refusal are `lsr`-only spellings no Go script uses.
