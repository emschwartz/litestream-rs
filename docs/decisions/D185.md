## D185. The simulator soaks optimized, and the engine's tests also run optimized

Status: decided · Decided by: Claude (claude-opus-5-5), 2026-11-24, **delegated**.

- **Question:** the soaks (`just sim-soak`, `just sim-nightly`) ran in the unoptimized dev build, where the workspace crates spend most of a run in iterator adapters and copies. Built at opt-level 1, the same 200 nightly seeds ran 2.3 to 3.2 times faster, but 7 of them took different histories and 2 never drained. The cause was a miscompile in rustc 1.99.1 to at least 1.102 of the boot's takeover gate (fixed in the same change, `BootGate::vouch` in `crates/core/src/actor.rs`). The engine ships optimized, so the dev-only simulator was not testing the code users run, and nothing ran the engine's tests optimized.
- **Choice:** a `sim` Cargo profile (dev with opt-level 1; debug assertions and overflow checks stay on). `just sim-soak`, `just sim-nightly` and `just sim-replay` use it, so a seed the nightly fails replays the same history. `just check` gains `test-opt`: the tests of lsr-core, lsr-sim and lsr-replica (the engine and both drivers) again under the `sim` profile. After the fix the 200 seeds give identical run reports in both builds.
- **Cost accepted:** `just check` builds those three crates a second time and runs about 1,700 tests again, about a minute here with dependencies already built. The rest of the workspace runs only unoptimized. The fixed-seed and scenario tests still run in both builds, but the soaks now sample only the optimized build: a defect that only the unoptimized build shows would be found by `test`, not by the nightly. A replay built without `--cargo-profile sim` may follow another history if the two builds ever diverge again; `test-opt` is there to make that a test failure first.
- **Options considered:** opt-level 1 on lsr-sim alone (it did not reproduce the miscompile, which needed lsr-core optimized too, so it would not test the shipped engine); the whole workspace in `test-opt` (2,824 tests, about 3.3 minutes here against about 1, for crates whose logic is not the engine's); opt-level 2 or 3 for the profile (not measured for speed; the lsr-replica regression test passes at both even on the old code, so they would have hidden this defect).
- **Links:** `justfile` (`test-opt`, `sim-soak`, `sim-nightly`, `sim-replay`), `Cargo.toml` (`[profile.sim]`), `crates/sim/tests/sim/empty_replica_boot.rs`, `crates/replica/tests/replica/replicator.rs`.
